# Aero 语言入门指南

## 简介

Aero 是一门面向 AI 时代的系统编程语言，旨在同时满足三个目标：Python 级别的开发速度、C++ 级别的运行时性能、以及 AI 原生的计算支持。Aero 在语法层面融合了 Rust 的所有权模型与函数式特性，同时内置了张量计算、自动微分和 GPU 加速等 AI 工作负载所需的基础设施。

Aero 的编译器采用 LLVM 后端，直接生成原生机器码，不依赖运行时或垃圾回收器。内存安全通过所有权和借用系统在编译期保证，无需 GC 开销。

## 安装与配置

### 编译器安装

从 Aero 官方仓库下载对应平台的二进制发行包。Windows 平台为 `.exe` 安装程序，Linux/macOS 为可执行归档。安装后确保 `aero` 可执行文件位于 `PATH` 环境变量中。

验证安装：直接运行 `aero` 打印全部可用命令与用法。

```bash
aero
```

### VS Code 插件

插件仅支持离线安装（未上架 VS Code 扩展市场）。下载最新的 `aero-lang-*.vsix` 后，在 VS Code 中通过「扩展 → … → 从 VSIX 安装」，或命令行执行：

```
code --install-extension aero-lang-1.1.0.vsix
```

安装后获得语法高亮；如需错误诊断，设置 `aero.lsp.executablePath` 指向本地 `aero.exe`。

## Hello World

```aero
print("Hello, Aero!\n");
```

Aero 没有 `fn main`（`main` 是保留字），可执行语句直接写在顶层。使用 `aero build` 编译，或 `aero run` 直接执行。

## 基础语法

### 变量与绑定

`let` 声明绑定，默认可变（`mut` 关键字不可用，无需也无法标注）。类型标注可省略，编译器自动推断。

```aero
let x = 42;           // i64
let y = 3.14;         // f64
y = 2.71;             // let 默认可变，可直接重新赋值
let z: i32 = 100;     // 显式类型标注
```

### 函数

函数使用 `fn` 关键字声明，返回值类型置于箭头 `->` 之后。无返回值的函数省略返回类型（不要写 `void`）。

```aero
fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

fn greet(name: str) {
    print("Hello, " + name);
}
```

### 控制流

```aero
let a = 5;
let b = 3;

// if / else 分支（条件必须带括号）
let max = 0;
if (a > b) {
    max = a;
} else {
    max = b;
}
print("max=%lld\n", max);

// while 循环（条件必须带括号）
let i = 0;
while (i < 3) {
    print("i=%lld\n", i);
    i = i + 1;
}

// loop 无限循环（配合 break 退出）
let n = 0;
loop {
    n = n + 1;
    if (n >= 3) {
        break;
    }
}

// for 循环（遍历数组字面量；Aero 不支持 0..n 范围语法）
for (j in [10, 20, 30]) {
    print("j=%lld\n", j);
}

// match 模式匹配（分支必须是语句块）
let x = 1;
match (x) {
    0 => { print("zero\n"); }
    1 => { print("one\n"); }
    _ => { print("other\n"); }
}
```

### Trait 与 Impl

Trait 的方法不使用 `self`，而是显式声明接收者参数：

```aero
struct Circle {
    radius: f64,
}

trait Shape {
    fn area(c: Circle) -> f64;
}

impl Shape for Circle {
    fn area(c: Circle) -> f64 {
        return 3.14159 * c.radius * c.radius;
    }
}
```

## 所有权与借用

Aero 采用与 Rust 相同的所有权规则：

- 每个值有且仅有一个所有者
- 所有权可通过赋值或函数调用转移（移动语义）
- 引用 `&` 允许借用而不转移所有权
- `&mut` 提供可变引用，同一作用域内只能有一个可变引用

```aero
// 所有权：s 被赋值给 t 后，所有权转移，s 不再可用
let s = String::from("hello");
let t = s;

// 传入即转移所有权
fn take_ownership(s: String) {
    print("ownership: %s\n", s.data());
}

// 仅借用，不转移所有权
fn borrow_len(v: &Vec<i64>) -> i64 {
    return v.len();
}

let w = Vec::new();
w.push(7);
w.push(8);
print("borrowed len=%lld\n", borrow_len(&w));

take_ownership(t);

// 可变借用：同一作用域内只能有一个可变借用
let v = Vec::new();
v.push(1);
let r1 = &mut v;
r1.push(2);
print("v len=%lld\n", r1.len());
// let r2 = &mut v;   // 编译错误：不能同时存在两个可变借用
```

## 标准库概览

Aero 标准库（`std.aero`）在编译时自动注入，无需手动引入。

- **Option\<T\>**：`Some(T)` / `None`，支持 `is_some`、`is_none`、`unwrap_or`
- **Result\<T,E\>**：`Ok(T)` / `Err(E)`，支持 `is_ok`、`is_err`、`unwrap_or`
- **Vec\<T\>**：动态数组，支持 `new`、`push`、`pop`、`get`、`set`、索引操作
- **String**：UTF-8 字符串，支持 `new`、`from`、`len`、`at`、`push`、`pop`、索引
- **HashMap\<V\>**：哈希映射（键为 `i64`），支持 `insert`、`get`、`contains`、`remove`
- **BTreeMap**：有序映射（键值均为 `i64`），支持 `insert`、`get`、`contains`、`remove`、`keys`
- **BTreeSet**：有序集合（`i64`），支持 `insert`、`contains`、`remove`、`to_vec`
- **LinkedList\<T\>**：双向链表，支持 `push_front/back`、`pop_front/back`、`get`、`set`、`remove`
- 排序：`sort`、`binary_search`、`reverse`（作用于 `Vec<i64>`）
- 函数式（内部实现）：`_filter_impl`、`_map_impl`、`_reduce_impl`（通过函数指针，作用于 `Vec<i64>`）

## 项目结构

每个 Aero 项目根目录包含 `Aero.toml` 配置文件：

```toml
[project]
name = "my_project"
version = "0.1.0"

[link]
libs = ["m"]
frameworks = []
```

源文件位于 `src/` 目录下。当前版本模块使用内联 `mod { ... }` 块声明（尚不支持 `mod file;` 文件模块），`use` 引入路径，`pub` 公开可见性。

```aero
// src/main.aero
mod math {
    pub fn add(a: i64, b: i64) -> i64 {
        return a + b;
    }
}

use math::add;

let sum = add(1, 2);
print("sum=%lld\n", sum);
```

```
aero new my_project     # 创建新项目

```

## FFI

通过 `extern "C"` 声明外部 C 函数（声明形式为 `extern "C" fn 名字(参数) -> 返回类型;`，不是 `extern { }` 块）：

```aero
extern "C" fn llabs(x: i64) -> i64;

let r = llabs(-10);
print("abs=%lld\n", r);
```

在 `Aero.toml` 的 `[link]` 段中指定链接库：

```toml
[link]
libs = ["m", "pthread"]
```
