What You'll Learn

Foundation

Variables, types, operators, control flow, functions — the building blocks every Aero program uses.

Core Type System

Generics, arrays, tuples, strings — with compile-time type inference and strict implicit-narrowing rejection.

Borrow Checker

References &T borrowing with NLL (Non-Lexical Lifetimes). Catch dangling pointers and data races at compile time.

Arena Memory

Scope-based region allocation. Zero GC pauses, no per-object free. Fast and predictable.

AI & Tensors

Built-in tensor types and matmul. Compile-time dimension checking for matrix multiplication.

Systems Interop

extern "C" FFI, Aero.toml [link] directives, file IO, command-line arguments, package manager and testing.

Compilation Pipeline

Understand the full pipeline: lexer → parser → HIR → LLVM IR → optimized machine code.

Appendices

Built-in function cheat sheet, common error reference, and a feature comparison table with C and Rust.
