# 18 附录 C：与 C 和 Rust 对照

Aero 站在 C 和 Rust 之间：语法和内存观感像 C，类型安全和借用思想来自 Rust，又加了自己的取舍（Arena、Tensor）。用你最熟悉的语言对照着看，上手最快。

## 变量

| 语言 | 写法 | 特点 |
| --- | --- | --- |
| C | `int x = 1;` | 必须写类型 |
| Rust | `let x = 1;` | 类型推断，默认不可变（`mut` 才可变） |
| Aero | `let x = 1;` | 类型推断，**默认可变**，无 `const` |

Aero 的 `let` 变量可以直接 `x = 2` 重新赋值，这点像 C 不像 Rust（Rust 要 `let mut x`）。

## 整数类型

| C | Rust | Aero |
| --- | --- | --- |
| `int` | `i32` | `i32` |
| `long long` | `i64` | `i64` |
| — | `usize` | 无（用 `i64`） |
| `_Bool` | `bool` | `bool` |

Aero 只有 `i32`/`i64`/`bool`/`str` 四种基本类型，没有 `unsigned`、没有浮点（0.1 版）。整数字面量默认 `i64`，可被注解适配 `i32`。

## 字符串

| C | Rust | Aero |
| --- | --- | --- |
| `char*`（NUL 结尾） | `&str`（长度前缀） | `str`（底层就是 `char*`） |

Aero 的 `str` 和 C 的 `char*` 是同一个东西，能直接传给 C 函数（第 12 章）。代价是 `len()` 要扫一遍（O(n)）。Aero 提供了比 C 丰富的字符串运算：拼接、六种比较、子串、查找、数字互转。

## 内存管理

| C | Rust | Aero |
| --- | --- | --- |
| `malloc` / `free`，全靠自觉 | 所有权 + 借用检查，编译期保证 | **Arena + 借用检查**，运行时零停顿 |

- C 把内存完全交给你，错了就泄漏/崩溃/写坏内存。
- Rust 用所有权和借用，编译器盯着，但学习曲线陡。
- Aero 走第三条路：**借用检查（学 Rust）+ Arena（块结束整体释放）**。不需要你逐个 `free`，也没有 GC 停顿。运行时分配（字符串）仍用 `malloc` 那套，用完 `str_free`。

## 借用

Aero 的借用规则就是 Rust 规则的简化版：

| 规则 | Rust | Aero 0.1 |
| --- | --- | --- |
| 多个不可变借用共存 | ✅ | ✅ |
| 可变借用排他 | ✅ | ✅ |
| 借用期间不能写源 | ✅ | ✅ |
| NLL（借用活到最后一次使用） | ✅ | ✅ |
| 引用作为返回值 | ✅ | ❌（暂不支持） |
| 引用存数组/嵌套 | ✅ | ❌（暂不支持） |

Aero 把最常用的几条规则先实现了，高级场景留给后续版本。

## 函数与泛型

```c
// C：每写一种类型，抄一遍或上宏
int max_int(int a, int b) { return a > b ? a : b; }
```

```rust
// Rust：泛型 + trait 约束
fn max<T: Ord>(a: T, b: T) -> T { if a > b { a } else { b } }
```

```aero
// Aero：泛型，实例化时检查操作合法性
fn max<T>(a: T, b: T) -> T {
    if (a > b) { return a; }
    return b;
}
```

三者都是编译期处理（Aero 和 Rust 都是单态化）。区别：Rust 用 trait 约束"T 支持什么操作"，Aero 0.1 简化成"实例化时才检查"，约束更宽松、错误更晚暴露。

## 数组

| C | Rust | Aero |
| --- | --- | --- |
| `int a[3]`，长度是类型一部分 | `[i32; 3]`，长度是类型一部分 | `[i64; 3]`，长度是类型一部分 |

C 和 Aero 都不做越界检查（C 是传统，Aero 是 0.1 版取舍）；Rust 的 `[]` 索引默认做边界检查（调试时）。元组方面 Aero 的 `(10, true)` 类似 Rust 的 `(i64, bool)`，但 Aero 用 `t[0]` 访问（Rust 用 `t.0`）。

## 一个总览表

| 特性 | C | Rust | Aero |
| --- | --- | --- | --- |
| 类型推断 | 无 | 有 | 有 |
| 垃圾回收 | 无 | 无 | 无 |
| 借用检查 | 无 | 有 | 有（简化版） |
| 内存自动管理 | 无（手动） | 所有权 | Arena |
| 字符串内建运算 | 少 | 多 | 多 |
| 泛型 | 无（宏凑） | 有（trait） | 有（宽松） |
| FFI 调 C | 原生 | extern | extern "C" |
| AI 矩阵 | 无 | 无 | `tensor` + `matmul` |
| 数组越界检查 | 无 | 调试时查 | 无（0.1） |
| 浮点 | 有 | 有 | 无（0.1） |

## 如果你从 C 来

- 忘掉 `malloc`/`free` 的日常：常用场景用 Arena，字符串用 `str_free`。
- 类型推断会惯坏你，但类型一旦定了就不会悄悄变窄。
- `if (x)` 不行了，要写 `if (x != 0)`。
- 你会被借用检查器拦几次，习惯就好——它拦下的是真 bug。

## 如果你从 Rust 来

- `let` 默认可变，不用写 `mut`（但可变借用还是要 `&mut`）。
- 没有所有权转移的概念：数组、元组都是"拷贝"语义，简单很多。
- 借用规则是 Rust 的子集：引用不能返回、不能嵌套。
- 内存管理：Arena 提供无 GC 停顿的块分配，`Vec` 提供动态数组，字符串要手动 `str_free`。

## 结尾

到这里，Aero 的 0.1 版能力你都过了一遍：变量、流程、函数、泛型、数组元组、字符串、借用、Arena、Tensor、FFI、文件 IO、命令行、包与测试。剩下的就是写。

Aero 还很年轻，缺的东西不少（浮点、break/continue、const、容器、类、模块……）。但骨架是对的：编译期多做功课、运行时保持干净。这本书会跟着语言一起更新。
