# 10 Arena 内存管理

## 内存管理的三种思路

写程序要动态分配内存时，语言一般给三种方案：

1. **手动分配/释放**（C 的 malloc/free）：灵活，但你要记得每次释放。忘了就泄漏，释放两次就崩溃。
2. **垃圾回收**（Java/Python）：自动，但运行时会有"停一下清垃圾"的停顿，且内存使用不可控。
3. **区域分配（Arena）**：**一次性**向系统要大块内存，程序在里面"顺序取用"，用完之后**整块还掉**。

Aero 走第三条路。这是它"三不原则"（不 GC、编译期做能做的事）在内存上的落点：arena 没有运行时停顿，也不需要逐个记账。

## 创建一个 Arena

```aero
let a = arena(64);
```

`arena(64)` 创建一个容量 64 字节的内存池。这个 `a` 就是你的"内存管理员"。

## 分配：alloc

```aero
let a = arena(64);
let p = a.alloc(2);   // 要 2 个槽
p[0] = 7;
p[1] = 9;
print(p[0] + p[1]);   // 16
```

`a.alloc(n)` 从池里划出 n 个槽，返回一个可以索引的指针：`p[0]`、`p[1]` 直接用。这里的"槽"是 8 字节（i64），所以 `alloc(2)` 实际占 16 字节池容量。

多个分配挨着排：

```aero
let a = arena(64);
let p = a.alloc(3);   // 第一个块
let q = a.alloc(2);   // 第二个块，接在后面
p[0] = 1;
q[0] = 10;
print(p[0] + q[0]);   // 11
```

## 池满了会怎样

`alloc` 超出剩余容量会调用 `abort()` 直接终止程序。这是"宁可错杀不可放过"——arena 越界是程序员的错，当场死给你看，而不是静默写坏内存。

```aero
let a = arena(8);
// let p = a.alloc(2);   // 要 16 字节，池只有 8，程序直接终止
```

## reset：重新使用

```aero
let a = arena(64);
let p = a.alloc(1);
p[0] = 5;

a.reset();            // 偏移归零：整个池可以重新分配

let q = a.alloc(1);
q[0] = 8;
print(q[0]);          // 8
```

`a.reset()` 把"已用标记"拨回零。注意它**不清数据**，只是允许新分配覆盖旧位置。旧指针 `p` 在 reset 之后就别用了（它指向的内存已经可以被 q 覆盖）。

场景：游戏里每帧要分配一堆临时对象，帧结束 `reset()`，下一帧从头用。零碎片、零释放开销。

## 块结束自动释放

Arena 绑定在它的作用域上。**花括号块结束，里面创建的 arena 自动重置**——你什么都不用做：

```aero
if (true) {
    let a = arena(64);
    let p = a.alloc(10);
    p[0] = 1;
    print(p[0]);   // 1
}
// 到这里 a 的内存已经整体归还，a 也不存在了
print(9);
```

这解决了一个大问题：第 8 章字符串那套"谁分配谁释放"，在 arena 世界里变成"块结束一起还"。这也是白皮书里说的"基于作用域的区域分配器，做到零运行时开销"。

## Arena 不可拷贝、不可移动

```aero
let a = arena(64);
// let b = a;   // 错误：Arena 不可拷贝或移动
// a = arena(32);  // 错误：Arena 变量不可重新赋值
```

为什么？arena 是"块内唯一的管理者"，拷贝一份出来等于两个管理者管同一块内存，乱套。所以它只能呆在它出生的作用域里，跟着作用域生灭。

## Arena vs malloc，什么时候用哪个

- 需要**成批**分配、一起释放 → arena，快、省事。
- 需要**单个对象活得比作用域久**（比如函数返回一个堆上字符串给调用者）→ 用字符串库的 malloc 那套（`int_to_str` 返回 + 调用者 `str_free`）。

Aero 0.1 还没有"把 arena 指针传给函数返回"的能力，所以跨函数生存的内存暂时只能走 malloc 系。这两套在 0.1 里并存，各有各的用处。

## 练习

1. 写一个循环：每次迭代从 arena 分配 1 个槽并写入迭代号，循环结束（块结束）后确认 arena 自动释放（在循环外用 `a` 会编译报错）。
2. 造一个 arena 溢出：容量 16，`alloc(3)`，观察程序终止行为。
3. 用一个 arena 模拟"打包 5 个学生的分数并求和"。
4. 思考：为什么 `arena(64)` 的字面量只能出现在 `let` 初始化里（它不能被塞进数组或作为函数参数）？提示：想想它的生命周期归谁管。
