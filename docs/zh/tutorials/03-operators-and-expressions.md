# 03 运算符与表达式

## 算术运算

```aero
print(1 + 2);    // 3
print(10 - 3);   // 7
print(7 * 6);    // 42
print(8 / 2);    // 4
print(-5 + 10);  // 5
```

运算符：`+` 加、`-` 减、`*` 乘、`/` 除、`-x` 一元负号。

几个要注意的地方：

- **整数除法直接截断**。`7 / 2` 的结果是 `3`，不是 `3.5`。Aero 0.1 只有整数，没有浮点类型。这是当前版本的限制。
- **除零不会崩溃**。Aero 在运行时检查除数是否为 0，如果除数为 0 则返回 0。但依赖"除零返回 0"来写逻辑通常是不好的习惯，建议自己确保除数不为 0。
- **优先级和 C 一样**：`* /` 高于 `+ -`，括号 `( )` 最高。

```aero
print(2 + 3 * 4);    // 14，不是 20
print((2 + 3) * 4);  // 20
```

## 比较运算

```aero
print(3 < 5);     // true
print(3 > 5);     // false
print(3 <= 3);    // true
print(3 >= 4);    // false
print(3 == 3);    // true
print(3 != 4);    // true
```

六个比较运算符：`<` `>` `<=` `>=` `==` `!=`。结果都是 `bool`。

比较的两边类型必须一致。`3 == 3.0` 这种直接编译错误（没有浮点，也不存在隐式转换）。

## 逻辑运算：短路

```aero
let x = 5;
print(x > 0 && x < 10);   // true
print(x < 0 || x > 100);  // false
print(true && false);     // false
print(true || false);     // true
```

`&&` 与、`||` 或，操作数必须是 `bool`。

**短路**的意思是：`&&` 左边是 `false` 时，右边根本不会执行；`||` 左边是 `true` 时，右边不执行。这很重要，因为它意味着你可以安全地写：

```aero
let i = 10;
if (i != 0 && 100 / i > 5) { print("ok\n"); }
```

`i != 0` 为假时，`100 / i` 不会真的去算，不会除零。

## print 的格式串

print 的第一个参数如果是字符串，它会被当作 C 风格的格式串，后面的参数按格式符填充：

```aero
print("%d + %d = %d\n", 6, 7, 6 * 7);   // 6 + 7 = 42
print("value is %d\n", 100);            // value is 100
print("%s is %d years old\n", "Aero", 1);  // Aero is 1 years old
```

- `%d` 填整数
- `%s` 填字符串

不写格式串、只打印一个数字也可以：

```aero
print(42);   // 输出 42（不带换行）
```

## 表达式和语句的区别

一个表达式是一个"有值的东西"：`1 + 2`、`x > 0`、`"abc"` 都是表达式。语句是"做一件事"：`print(x);`、`let y = 5;` 是语句。

在 Aero 里，`print(表达式);` 后面一定要有分号。漏分号是最常见的编译错误：

```
错误: line 1 col 9 [语法分析] expected `;`, found ...
```

看到这条，先去上一行找分号。
