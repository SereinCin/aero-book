# 02 变量与类型

## 声明一个变量

Aero 用 `let` 声明变量：

```aero
let x = 1;
print(x);   // 输出 1
```

不需要写类型，编译器自己会推。上面这行 `x` 被推导成 64 位整数。

Aero 有四种基本类型：

| 类型 | 含义 | 字面量例子 |
| --- | --- | --- |
| `i64` | 64 位有符号整数 | `42`、`-7` |
| `i32` | 32 位有符号整数 | 整数，由注解决定 |
| `bool` | 布尔 | `true`、`false` |
| `str` | 字符串 | `"hello"` |

## 类型推导的规则

Aero 的类型推导有个重要的细节：**整数字面量的类型是"可伸缩"的**。

```aero
let x = 1;          // x 是 i64
let y: i32 = 1;     // 合法！字面量 1 可以适配 i32
let z: i32 = x;     // 报错！x 已经是 i64，塞进 i32 是隐式窄化
```

规则是：**整数字面量**（`1`、`2 + 3` 这种）可以被注解成 `i32` 或 `i64`，谁注解它它听谁的；但如果一个变量已经定了类型（比如 `x` 是 `i64`），再把它赋值给 `i32` 的变量，编译器拒绝——它不偷偷帮你截断。

这个规则是刻意的。隐式窄化是 C/C++ 里最常见的 bug 来源之一：一个大数被悄悄截断成小类型，程序行为完全错误但编译不报错。Aero 选择在编译期就拦住。

记住一句话：**类型一旦确定，就不会再变窄**。

## 显式注解

想写清楚类型就用冒号：

```aero
let n: i64 = 10000000000;   // 十亿级，必须 i64
let small: i32 = 5;
let flag: bool = true;
let name: str = "Aero";
```

什么时候需要显式注解？

- 字面量超出默认推断范围时（虽然整数字面量默认 i64，但写清楚更保险）；
- 空数组、空字符串这种推不出元素的场景（第 7、8 章讲）；
- 代码可读性需要时。

## 变量可以重新赋值

`let` 声明之后，变量不是常量，可以改：

```aero
let x = 1;
x = x + 1;
print(x);   // 输出 2
```

用 `=` 重新赋值。赋值时新值的类型必须和原类型一致，不允许窄化：

```aero
let x: i32 = 1;
x = 2;          // OK
// x = 100000000000;   // 编译错误：值超出 i32 范围（隐式窄化）
```

## 块作用域

`{ }` 花括号构成一个块。块里声明的变量，块结束就失效：

```aero
let a = 1;
if (true) {
    let b = 2;
    print(a + b);   // 输出 3，a 在外面也能用
}
// print(b);        // 错误：b 在这里不存在
```

外面的变量里面能用，里面的变量外面用不了。这是所有类 C 语言的共同规则，Aero 也一样。

另外：**同一个作用域里不允许重复声明同名变量**。

```aero
let x = 1;
// let x = 2;   // 错误：变量 `x` 在当前作用域重复声明
```

## 一个细节：没有 `const` 关键字

Aero 0.1 没有 `const`，所有变量都可重新赋值。想让一个值"只读"，靠的是约定，不是编译器强制。这在后续版本会改进。

## 练习

1. 声明一个 `i32` 变量、一个 `i64` 变量、一个 `bool` 变量，各赋一个值，分别 `print` 出来。
2. 写一段代码，故意把 `i64` 变量赋值给 `i32` 变量，观察编译错误信息。
3. 在 `if` 块里声明变量，块外用 `print` 打印它，观察错误，然后改正。
