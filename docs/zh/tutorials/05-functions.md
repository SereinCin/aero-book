# 05 函数

## 定义一个函数

```aero
fn add(a: i64, b: i64) -> i64 {
    return a + b;
}

print(add(1, 2));   // 3
```

结构拆开看：

- `fn` 关键字声明函数；
- `add` 是函数名；
- `(a: i64, b: i64)` 是参数列表，每个参数 `名字: 类型`；
- `-> i64` 是返回类型；
- `{ ... }` 是函数体；
- `return` 返回值。

## 没有返回值的函数

返回类型可以省略，这样的函数"做事情但不给结果"：

```aero
fn greet(name: i64) {
    print("hello %d\n", name);
}

greet(7);   // hello 7
```

## 参数是拷贝的

Aero 的函数参数按值传递：函数里改参数，不影响调用者的变量。

```aero
fn bump(n: i64) {
    n = n + 1;
    print("inside: %d\n", n);   // inside: 11
}

let x = 10;
bump(x);
print("outside: %d\n", x);      // outside: 10，没变
```

想改调用者的变量，用引用（第 9 章）或让它返回新值。

## 递归

函数可以调用自己：

```aero
fn fact(n: i64) -> i64 {
    if (n <= 1) { return 1; }
    return n * fact(n - 1);
}

print(fact(5));   // 120
```

这是最标准的递归例子。递归函数必须有一个"终止条件"（`n <= 1`），否则无限递归直到栈溢出。

Aero 为递归程序分配了 64MB 的栈空间（相比默认的 ~1MB 大幅提升），可以安全地递归数万层。但"无限递归"仍然会栈溢出——终止条件永远是必须的。

## 前向调用：函数可以定义在后面

Aero 编译时分两遍扫描：第一遍收集所有函数签名，第二遍才生成代码。所以函数**可以互相调用、可以调用定义在后面的函数**：

```aero
fn is_even(n: i64) -> i64 {
    if (n == 0) { return 1; }
    return is_odd(n - 1);
}

fn is_odd(n: i64) -> i64 {
    if (n == 0) { return 0; }
    return is_even(n - 1);
}

print(is_even(10));   // 1（真）
print(is_odd(7));     // 1（真）
```

`is_even` 调用 `is_odd` 时，`is_odd` 还没定义——没关系，编译器已经知道它的签名了。

## 作用域规则

- 函数体是独立的块：函数里的变量、参数，外面都看不见。
- 函数参数在函数内可以重新赋值（上面 `bump` 里的 `n = n + 1`）。
- **函数定义不能嵌套**：函数体里不能再写 `fn`。所有函数都是顶层定义。

```aero
fn outer() {
    // fn inner() {}   // 错误：函数定义不允许嵌套在函数体内
}
```

## 函数调用不能缺少返回值类型检查

一个常见困惑：为什么 `return` 写不写都有讲究？

- 声明了 `-> i64`，函数里 `return` 必须带值。
- 没声明返回类型，`return` 不能带值。

```aero
fn f() -> i64 {
    return 1;   // 必须带值
}

fn g() {
    return;     // 空 return，提前结束
    // return 1;  // 错误
}
```
