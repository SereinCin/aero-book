# Aero Programming

A beginner's guide to the Aero language, written for humans. Goal: after reading this book, you'll be able to write complete, runnable Aero programs that compile into standalone executables.

Corresponding Aero version: **1.2.0** (2026).

## Usage Notes

- All example code has been verified and can be run directly.
- It is recommended to type along as you read — don't just skim.
- Each chapter ends with exercises; complete them before moving on.
- This book is written for the Windows environment (Aero currently runs primarily on Windows). macOS/Linux users only need to adjust the installation steps; the syntax is identical.
