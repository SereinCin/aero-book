对应 Aero 版本：**0.1.1**（2026）。

## 使用说明

- 全部示例代码都经过验证，可以直接跑。
- 建议边读边敲，不要只看。
- 每章末尾有练习，做完再进下一章。
- 本书按 Windows 环境讲解（Aero 目前主要跑在 Windows），macOS/Linux 用户只需改安装步骤，语法完全一样。
