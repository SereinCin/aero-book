# 06 泛型

## 问题：同一段逻辑，多种类型

想写一个"返回两个参数中较大者"的函数。整数可以，但字符串比较大小也合理，`i32` 也行。为每种类型抄一份？

```aero
fn max_i64(a: i64, b: i64) -> i64 {
    if (a > b) { return a; }
    return b;
}
```

然后还要 `max_i32`、`max_str`……烦。

泛型就是干这个的：**写一次，编译器按需生成多个版本**。

## 语法：`<T>`

```aero
fn max<T>(a: T, b: T) -> T {
    if (a > b) { return a; }
    return b;
}

print(max(3, 7));    // 7
print(max(10, 5));   // 10
```

`<T>` 声明了一个类型参数。函数签名里所有 `T` 表示"同一个类型"：参数 `a` 和 `b` 必须同类型，返回值也是这个类型。

调用时**不需要写类型参数**，编译器从实参推：`max(3, 7)` 里两个整数，`T` 就是整数。

## 为什么 `a > b` 合法

`max<T>` 里写了 `a > b`。泛型参数 `T` 还没确定，凭什么能比大小？

Aero 的规则：**泛型参数在签名内部未确定时宽松通过，实例化时按具体类型检查**。`max(3, 7)` 实例化 `T = i64`，此时 `i64 > i64` 合法，编译通过。如果你用一个不支持 `>` 的类型去调用（比如 `bool`），实例化时报错。

## 一个函数，多个类型参数

```aero
fn make_pair<A, B>(a: A, b: B) -> (A, B) {
    return (a, b);
}

let p = make_pair(100, true);
print(p[0]);   // 100
print(p[1]);   // true
```

`A` 和 `B` 是两个独立的类型参数，可以不同。

## 泛型数组参数

```aero
fn first<T>(arr: [T; 3]) -> T {
    return arr[0];
}

let nums = [1, 2, 3];
print(first(nums));   // 1
```

注意这里数组长度是固定的 `[T; 3]`——Aero 0.1 的泛型不支持"任意长度数组"，长度也是类型的一部分（第 7 章细说）。

## 泛型函数调用泛型函数

```aero
fn identity<T>(x: T) -> T {
    return x;
}

fn wrap<T>(x: T) -> T {
    return identity(x);   // 泛型里再调泛型
}

print(wrap(42));   // 42
```

编译器会一层层展开：`wrap(i64)` 内部调用 `identity(i64)`，生成两份代码。

## 单态化：代价和收益

Aero 的泛型是**单态化**的：每遇到一组具体类型参数，就生成一份独立的机器码。

- 收益：没有运行时开销，`max(i64)` 和手写的 `max_i64` 一样快，类型安全是编译期保证的。
- 代价：`max(3, 7)` 和 `max(1, 2)` 如果类型不同，会生成两份代码，程序体积变大。同类型重复调用只生成一份（编译器会去重）。

## 一个限制

泛型参数名不能和内置类型名冲突：

```aero
// fn bad<i64>(x: i64) -> i64 { return x; }   // 错误：泛型参数名与内建类型名冲突
```

`i64`、`i32`、`bool`、`str` 这些名字被类型系统占用，不能拿来当泛型参数名。用 `T`、`U`、`A`、`B` 这类单字母最省事。

## 练习

1. 写一个 `identity<T>` 并分别用整数、字符串调用。
2. 写一个泛型函数 `second<T>(t: (T, T)) -> T` 返回元组的第二个元素，调用验证。
3. 用 `max<T>` 比较两个字符串（`"abc"` 和 `"abd"`），看谁大。
4. 思考：为什么 Aero 不提供 `max` 这种泛型为内置函数？（提示：任何类型都能比较大小吗？）
