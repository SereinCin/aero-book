# 00 前言

## Aero 是什么

Aero 是一门系统级编程语言。这句话的意思可以拆开讲：

- **系统级**：它编译成机器码，没有虚拟机，运行时没有垃圾回收器。写出来的程序跑得快，内存可控，可以直接和操作系统、C 库打交道。
- **编程语言**：它有自己的语法、类型系统、编译器。你用 Aero 写代码，编译器把代码变成可执行文件。

Aero 的目标是：写起来像 Python 一样省事，跑起来像 C++ 一样快。这不是口号，是设计取舍的结果。Aero 把大量的工作在编译期做完——类型推导、内存检查、甚至一部分代码展开——运行时只留下真正必要的东西。

三个设计底线（Aero 的"三不原则"）：

1. **不要垃圾回收**。GC 会在你程序运行到一半的时候突然停下来清扫内存，这种停顿对系统级程序不可接受。Aero 用别的方式管内存（见第 10 章 Arena）。
2. **能在编译期做的事，绝不留到运行时**。类型推导、内存布局，都在编译阶段解决。
3. **不重复造轮子**。Aero 不自己写机器码生成器，它把中间表示交给 LLVM，让 LLVM 去生成高质量的原生代码。

## 这本书写给谁

- 你写过一点代码，语言不限——Python、JavaScript、C、Java 都行。
- 你想知道"没有垃圾回收的语言怎么写程序"。
- 你想写一个能编译成独立 .exe 的小工具。

你不需要会 C++，也不需要懂编译原理。第 15 章会简单讲 Aero 的编译流程，那只是让你心里有数，不是门槛。

## 怎么读这本书

按顺序读。前八章是地基（变量、流程、函数、数组、字符串），第九章（借用）和第十章（Arena）是 Aero 的灵魂，值得多花时间。第十一章之后是按需阅读——写数值计算看第十一章，调 C 库看第十二章，做命令行工具看第十三章。

每章的结构都一样：先讲概念，再给能跑的代码，然后讲"坑"，最后有练习。代码你最好亲手敲一遍——敲错一次记住的，比读十遍牢靠。

## 关于"快"

很多人第一次跑 Aero 会问：为什么编译出来的程序比 Python 快这么多？

答案不神秘。Python 在运行时解释每一行代码、动态查类型、用引用计数管理对象。Aero 在编译时就把类型定死、把内存布局定好、生成原生机器码。第 15 章你会看到这整个流程。记住结论：**Aero 把复杂度从运行时搬到了编译时**，而编译时做的功课，程序运行时不用再付账。

## 一个约定

本书所有代码块顶部的注释（`// ...`）只是说明，不影响运行。你可以删掉注释，程序行为不变。
