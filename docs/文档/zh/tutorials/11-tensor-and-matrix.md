# 11 Tensor 与矩阵

## 为什么要 Tensor

Aero 的定位之一是"原生支持 AI 计算"。AI 计算的核心是矩阵运算。Aero 内置了张量（Tensor）类型和矩阵乘法 `matmul`，这是它区别于普通系统语言的地方。

Tensor 可以理解成"多维数组，天生支持数学运算"。`tensor(2, 3)` 就是一个 2 行 3 列的矩阵。

## 创建与读写

```aero
let a = tensor(2, 3);   // 2 行 3 列，零初始化
print(a[0][0]);   // 0
print(a[1][2]);   // 0
```

所有元素初始为 0。用多维索引读写：

```aero
let a = tensor(2, 2);
a[0][1] = 5;
print(a[0][1]);   // 5
print(a[1][1]);   // 0，没动过
```

## 一维张量：向量

```aero
let v = tensor(4);   // 长度 4 的向量
v[2] = 7;
print(v[2]);   // 7
print(v[0]);   // 0
```

一维张量索引一次就是标量。

## 子张量

多维张量索引**一次**得到的是"子张量"（少一维），还能继续索引：

```aero
let a = tensor(2, 3);
a[1][2] = 9;
let row = a[1];        // 取第 1 行，类型是 3 元素的一维张量
print(row[2]);         // 9
```

## 矩阵乘法：matmul

```aero
let a = tensor(2, 2);
let b = tensor(2, 2);
a[0][0] = 1; a[0][1] = 2;
a[1][0] = 3; a[1][1] = 4;
b[0][0] = 5; b[0][1] = 6;
b[1][0] = 7; b[1][1] = 8;

let c = matmul(a, b);
print(c[0][0]);   // 19 = 1*5 + 2*7
print(c[0][1]);   // 22 = 1*6 + 2*8
print(c[1][1]);   // 50 = 3*6 + 4*8
```

## 维度规则

矩阵乘法要求 **左矩阵的列数 = 右矩阵的行数**。结果的行数 = 左矩阵行数，列数 = 右矩阵列数：

```aero
let a = tensor(1, 3);   // 1 行 3 列
let b = tensor(3, 2);   // 3 行 2 列
let c = matmul(a, b);   // OK：3 == 3
// c 是 1 行 2 列
print(c[0][1]);
```

维度不匹配，**编译期直接报错**：

```aero
let a = tensor(2, 3);
let b = tensor(2, 3);
// let c = matmul(a, b);   // 编译错误：2×3 与 2×3 无法相乘（左列 3 ≠ 右行 2）
```

两个张量的元素类型不一致也会报错。

## matmul 的参数必须是张量

```aero
// let c = matmul(1, 2);   // 编译错误：matmul 参数必须是二维张量
```

## 现在没有的

Aero 0.1 的 Tensor 只有零初始化和 matmul，没有加法、转置、点乘等。它是"AI 原生"的第一块砖——后面的版本会逐步加算子，并接上 GPU。

## GPU kernel：给未来留的口子

Aero 支持声明 GPU kernel：

```aero
extern "gpu" fn add_kernel(a: i64) {}
```

`extern "gpu"` 声明一个 GPU 上的函数。0.1 里它只是"声明合法、不执行、不能从 CPU 代码调用"，真正的 NVPTX 后端在路线图上。你知道有这个东西就行，暂时用不上。

## 练习

1. 创建 `tensor(3, 3)`，把对角线元素都设为 1（单位矩阵），打印 `m[2][2]` 验证。
2. 写两个 2×3 和 3×2 的矩阵做 `matmul`，手算验证结果的每个元素。
3. 试试 `matmul` 两个维度不匹配的矩阵，读编译错误。
