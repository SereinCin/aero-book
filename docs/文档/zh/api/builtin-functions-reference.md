# 16 附录 A：内建函数速查

## 输出

| 函数 | 说明 |
| --- | --- |
| `print(x)` | 打印一个值（整数直接打印，不带换行） |
| `print("格式串", a, b, ...)` | 按格式串打印：`%d` 整数、`%s` 字符串 |

## 断言与测试

| 函数 | 说明 |
| --- | --- |
| `assert(cond)` | 条件为假则打印诊断并终止程序（非零退出码） |
| `assert_eq(a, b)` | 两个值不等则失败终止 |

## 字符串

| 函数 | 说明 |
| --- | --- |
| `len(s)` | 字符串长度（字节数） |
| `s1 + s2` | 拼接（字面量拼接零开销；含变量时为运行时分配，结果需 `str_free`） |
| `s1 == s2` / `!=` / `<` / `>` / `<=` / `>=` | 字典序比较 |
| `s[i]` | 第 i 个字节的数值（`i64`） |
| `int_to_str(n)` | 整数 → 字符串（**运行时分配，需 `str_free`**） |
| `str_to_int(s)` | 字符串 → 整数（解析失败返回 0） |
| `substr(s, start, end)` | 取 `[start, end)` 子串，边界自动截断（**需 `str_free`**） |
| `str_contains(hay, needle)` | hay 中是否包含 needle（`bool`） |
| `str_find(hay, needle)` | needle 首次出现的位置，找不到返回 -1 |
| `str_cmp(a, b)` | C 风格比较，返回负数 / 0 / 正数 |
| `str_free(s)` | 释放运行时分配的字符串 |

## 数值计算

| 函数 | 说明 |
| --- | --- |
| `matmul(a, b)` | 二维张量矩阵乘法（左列 = 右行，编译期检查） |

## 文件与命令行

| 函数 | 说明 |
| --- | --- |
| `read_file(path)` | 读整个文件为字符串，失败返回空串 |
| `write_file(path, contents)` | 写文件，返回字节数，失败返回 -1 |
| `arg_count()` | 命令行参数总个数（含程序名，即 C 的 `argc`） |
| `arg(i)` | 第 i 个参数（`arg(1)` 是第一个参数），越界返回空串 |

## 运算符速查

| 类别 | 运算符 |
| --- | --- |
| 算术 | `+` `-` `*` `/` 一元负号 `-x` |
| 比较 | `<` `>` `<=` `>=` `==` `!=` |
| 逻辑 | `&&`（与）`||`（或），均短路 |
| 引用 | `&x`（不可变借用）`&mut x`（可变借用）`*r`（解引用） |
| 索引 | `a[i]` 读写；元组索引必须是常量 |

## Vec 动态数组

| 函数 | 说明 |
| --- | --- |
| `Vec::new()` | 创建空 Vec |
| `Vec::with_cap(n)` | 创建预分配容量为 n 的 Vec |
| `v.push(x)` | 末尾追加元素 |
| `v.pop()` | 弹出末尾元素，空 Vec 返回 0 |
| `v.len()` | 返回元素个数 |
| `v.is_empty()` | 是否为空 |
| `v.get(i)` | 读第 i 个元素（越界返回 0） |
| `v.set(i, x)` | 写第 i 个元素（越界忽略写入） |

## 集合类型

| 函数 | 说明 |
| --- | --- |
| `hash_map_new()` | 创建 HashMap |
| `m.insert(k, v)` | 插入键值对 |
| `m.get(k, def)` | 取键对应的值，不存在返回 `def` |
| `m.contains(k)` | 是否包含键 |
| `m.remove(k)` | 移除键值对 |
| `m.len()` | 返回条目数 |
| `btree_map_new()` | 创建 BTreeMap（有序） |
| `bm.keys()` | 获取键列表（`Vec`） |
| `btree_set_new()` | 创建 BTreeSet |
| `bs.contains(x)` | 是否包含元素 |
| `linked_list_new()` | 创建 LinkedList |
| `ll.push_front(x)` | 头部插入 |
| `ll.push_back(x)` | 尾部插入 |
| `ll.front()` | 返回头部元素（`Option<T>`，空返回 `None`） |
| `ll.back()` | 返回尾部元素（`Option<T>`，空返回 `None`） |

## 算法

| 函数 | 说明 |
| --- | --- |
| `sort(v)` | 对 Vec 原地排序（升序） |
| `reverse(v)` | 对 Vec 原地反转 |
| `binary_search(v, x)` | 二分查找，返回索引；未找到返回 -1 |
