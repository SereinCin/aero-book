# Aero Programming

A beginner's book on the Aero language, written for humans. Goal: after finishing this book, you can write complete, runnable programs in Aero that compile into standalone executables.

Corresponding Aero version: **0.1.1** (2026).

## How to Use This Book

- All example code has been verified and runs directly.
- Recommended to type along as you read, not just skim.
- Each chapter ends with exercises—finish them before moving on to the next chapter.
- This book is taught in a Windows environment (Aero currently runs mainly on Windows); macOS/Linux users only need to adjust the installation steps. The syntax is identical.
